## Features

- **Cyberpunk / HUD Aesthetic** — Scanline overlays, noise texture, grid backgrounds, glitch effects
- **Animated Hero Section** — Rotating orbital rings, animated core, live clock, HUD readouts
- **Blueprint Card** — SVG schematic of a cyborg unit with annotation lines
- **Augmentation Tech Cards** — 6-card feature grid with hover effects
- **Tech Specifications Table** — System specs with status indicators
- **Typewriter Terminal** — Animated boot sequence terminal widget
- **Animated Stats** — Counter animation triggered on scroll
- **Responsive Design** — Works on desktop, tablet, and mobile
- **Smooth Scroll Navigation** — Anchor-based nav with active section highlight

---

## Tech Stack

- Pure HTML5, CSS3, JavaScript (Vanilla)
- Google Fonts: Orbitron, Share Tech Mono, Rajdhani
- No frameworks, no dependencies — runs instantly in any browser

## Running Locally

```bash
git clone https://github.com/YOUR_USERNAME/nexus-7-landing.git
cd nexus-7-landing
# Open index.html in your browser — no build step needed
```

Or with VS Code Live Server: right-click `index.html` → **Open with Live Server**

---

## Deployment (GitHub Pages)

1. Push to GitHub
2. Go to repo Settings → Pages
3. Source: `main` branch, `/ (root)`
4. Your site will be live at `https://YOUR_USERNAME.github.io/nexus-7-landing`
